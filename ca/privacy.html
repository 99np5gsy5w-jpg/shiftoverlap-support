Privacitat, amb espai per respirar.

Kinly va ser desenvolupat per John Barney. Aquesta política descriu l'aplicació per a iPhone i iPad i aquest lloc de suport.

Calendari locals i compartir opcional amb iCloud

L'aplicació emmagatzema els noms familiars, els horaris recurrents, les activitats, les cites, les configuracions de son, les excepcions, les llistes, els elements de les llistes, les quantitats, les tasques, les dates de venciment, les notes i les preferències que introduïu en un espai d'emmagatzematge local i segur. Calcula la disponibilitat compartida al vostre dispositiu. No operem un servidor d'horaris independent, no recopilem dades analítiques de l'aplicació, no utilitzem SDKs publicitaris ni feu un seguiment de les vostres dades. La funció opcional de compartició familiar permet descarregar tot el calendari a CloudKit d'Apple, utilitzant el vostre compte iCloud. Els noms, els horaris, les activitats, les cites, les configuracions de son, les llistes i les notes són accessibles a tots els participants convidats. Cada participant utilitza el seu propi compte d'Apple; la informació d'identitat d'iCloud s'utilitza per a les invitacions i la gestió de l'accés. El calendari és privat per als participants convidats i no està disponible públicament a través d'un enllaç.

Accés a la llista i als annexos

Totes les llistes familiars, incloses les que s'adjunten als elements del calendari, utilitzen les mateixes autoritzacions d'accés a l'àmbit familiar que el calendari. Tots els membres convidats poden visualitzar totes les llistes i les seves notes. Els membres amb accés de només lectura no poden marcar ni editar elements. Assignar un element a una persona no limita el seu públic. No hi ha una configuració de privadesa específica per a cada llista. Les llistes es mantenen locals quan la compartició a l'àmbit familiar no està activada. Eliminar un element del calendari desvincula les seves llistes sense eliminar-les; per eliminar la llista, feu-ho de manera independent quan ja no sigui necessària.

Seleccioneu de la llista de contactes

Els contactes són opcionals. Kinly només rep el contacte que seleccioneu. Un nom seleccionat es guarda amb la programació; un correu electrònic escollit per a una invitació s'envia a Apple per sol·licitar l'accés. La vostra llista d'adreces no es descarrega.

Còpia de dispositiu i eliminació

El copia de seguretat del teu dispositiu Apple pot incloure dades d'aplicacions, segons les teves configuracions de còpia. Per a un calendari compartit, el propietari pot utilitzar "Aturar compartir" i mantenir una còpia local per eliminar el calendari en núvol i finalitzar l'accés de tothom. Els convidats poden sortir sense eliminar les dades del propietari. Els propietaris poden eliminar participants individuals mitjançant els controls de compartició. Eliminar l'accés no restaura les còpies que ja hagin estat exportades o guardades pels participants. Desinstal·lar l'aplicació no elimina el calendari en núvol. "Troba el meu calendari compartit" reconecta els calendaris existents després de reinstal·lar. Pel que fa a les dades personals, "Configuració → Restablir dades guardades" elimina els programes, les activitats, les excepcions i les llistes actives. Si un fitxer guardat no pot ser llegit, l'aplicació conserva una còpia de recuperació abans de restablir. Eliminar l'aplicació elimina els seus fitxers locals. Apple gestiona les còpies de dispositiu de manera independent. Restableix o desinstal·la no cancel·len les subscripcions.

Històric de canvis compartit i notificacions d'actualització

Els canvis als elements del calendari compartit i a les llistes també conserven el nom d'exhibició que ha triat l'editor, l'identificador de creador de registres proporcionat per Apple, la data i una descripció dels canvis al compartit privat de CloudKit del calendari. Aquesta història és visible per als participants convidats i inclou detalls com els noms de família, els títols dels esdeveniments, els títols de les llistes/elements, l'estat d'acabament, les quantitats, les assignacions, les dates de venciment i les dates antigues/noves. El text de les notes i les notes de les llistes no es copien a les descripcions dels canvis; el propi compartit familiar continua sent el que conté les notes. Les actualitzacions recents conserven fins a 100 entrades localment; l'història en la clou, es manté amb el calendari compartit fins que el propietari deixa de compartir-lo. Els noms d'exhibició són elegits per cada persona i no es verifiquen com a identitats reals.

Les notificacions de canvi de programació són opcionals per dispositiu i es diferencien de les notificacions d'esdeveniments. Les notificacions d'actualització activades mostren els noms i els canvis per defecte; podeu desactivar els detalls o silenciar-les a Configura → Actualitzacions del calendari i llistes. Els noms, les cites i els detalls de les llistes poden aparèixer a la pantalla bloquejada quan les notificacions estan activades. Silenciar no elimina l'històric i les actualitzacions prèviament rebudes no es reprodueixen quan es desactiven. L'aplicació no envia una notificació per a les vostres pròpies edicions. iOS pot retardar la entrega en fons; obrir l'aplicació sincronitza. Les preferències de notificació i silenci es mantenen locals.

Recordatori opcional

L'autorització per a les notificacions i les preferències de recordatoris es configuren en cada dispositiu. Els recordatoris que vénen, es programen localment a partir del calendari més recent descarregat. Les notificacions silenciades de iCloud poden provocar actualitzacions del calendari, però la entrega en fons no està garantida. Els avisos amaguen els noms dels esdeveniments, a menys que triï mostrar-los. Les eleccions de recordatoris no es comparteixen amb altres membres de la llar.

Decide vosaltres quines imatges compartir

L'aplicació pot crear una imatge de calendari amb els moments en què esteu disponibles junts. Els noms es descuiden per defecte i es poden incloure. No s'inclouen detalls de canvi ni notes. No s'envia res fins que trieu un destinatari a la pestanya d'compartir d'iOS. Els destinataris poden desar o reenviar les imatges; eliminar els vostres programes no elimina les còpies que ja s'han compartit.

Reseves opcionals de l'App Store

L'aplicació podria demanar una valoració utilitzant el formulari estàndard d'Apple després d'un ús significatiu durant diversos dies. Els petits temporitzadors i l'historial d'intent de formulari es mantenen al teu dispositiu i no contenen cap informació de calendari ni identificadors d'account; no s'envien al desenvolupador. Apple decideix si mostrar el formulari. També pots obrir la pàgina de revisió de l'App Store des de les Preferències. No sabem si envies una valoració o revisió. Les revisions enviades a Apple són gestionades per ells segons les seves polítiques.

Subscripcions a través d'Apple

Apple gestiona les subscripcions i la informació de pagament. L'aplicació utilitza StoreKit per verificar les transaccions signades, l'accés actual i l'elegibilitat per a les proves. No rebem dades de targeta de pagament. Les operacions de recuperació de productes, compra i restauració es connecten amb Apple. Apple pot proporcionar al desenvolupador informes de vendes i diagnòstics estàndard, d'acord amb les seves polítiques i les vostres configuracions del dispositiu.

Aquest lloc web i el seu suport

Aquest lloc web s'allotja a través de GitHub Pages. No afegim cookies, publicitat ni eines d'anàlisi. GitHub pot processar informació sobre les connexions, com ara adreces IP, d'acord amb les seves declaració de privacitatGitHub Issues s'utilitza per a suport i és públic. Els comentaris es gestionen segons les polítiques de GitHub. Si us plau, utilitzeu detalls de calendari ficticis i no publiqueu informació personal o sensible. El desenvolupador utilitza els comentaris de suport per respondre i millorar l'aplicació.

Contactar i canvis

Les preguntes sobre aquesta política es poden plantejar en el repositori de suport Sense publicar dades privades. Els canvis de política es faran constar a aquesta pàgina.

Recuperar les edicions privades i sense desar

Les versions incompletes i les còpies de recuperació de conflictes s'emmagatzemen amb protecció de fitxers al vostre dispositiu i estan vinculades al calendari original. No es comparteixen fins que no deseu explícitament els canvis. Les noves dades de canvis inclouen camps estructurats per a la visualització en la llengua del lector; el text de les notes privades s'exclou de les descripcions de les actualitzacions. Les preferències de recordatori i comparació segueixen sent pròpies de cada dispositiu.

Espai privat · Només membres amb l'aprovació del propietari

L'espai privat només està disponible per al propietari i per les Comptes Apple expressament autoritzats. Els plans privats, les llistes independents i les llistes enllaçades, les confirmacions d'activitat i l'historial de canvis utilitzen una compartició iCloud restringida i separada. L'accés a l'edició familiar no concedeix accés privat. Les notificacions privades mostren només un text genèric. Les còpies en memòria cau i les còpies de recuperació es xifren en aquest dispositiu i es queden excloses de les còpies de seguretat del dispositiu. Les àrees privades compartides requereixen una verificació d'accés en línia i un desbloqueig amb reconeixement biomètric o un PIN privat. Els dispositius que utilitzen el mateix Compte Apple comparteixen les autoritzacions d'aquest compte.

L'administrador accepta l'accés "Només lectura" o "Pot editar" de manera independent, un cop la persona s'ha unit al calendari familiar. Una invitació privada ha de ser acceptada abans que comenci l'accés. La nova aprovació inclou els plans, les llistes i l'historial privats existents. Eliminar l'accés familiar a través de Kinly elimina primer l'accés privat. Per als canvis realitzats fora de Kinly, l'aplicació de l'administrador sincronitza les comparticions individuals quan torna a connectar. Les imatges que s'han exportat anteriorment no es poden recuperar.

A "Privat Espai", seleccioneu "Troba temps per a nosaltres". Trieu exactament dos calendaris d'adults i cada nen per a qui sigui important tenir en compte la disponibilitat. Confirmeu les activitats on no es necessiten ambdós adults, i després afegiu els temps per deixar i recollir els nens. Ambdós adults han d'estar disponibles mentre tots els nens seleccionats estiguin ocupats durant tot el període. El descans no es considera una cura independent. Reviseu els plans quan els calendaris canvïin.

La funció de deixar de compartir conserva una còpia privada i encriptada al dispositiu del propietari. Accediu a "Espai Privatiu" → "Plans privatius" → "Còpies de recuperació privades" per restaurar-les en un espai privatiu buit o per eliminar una còpia. Es necessita el vostre compte d'Apple original per a una còpia de recuperació al núvol. Restablir les dades desades elimina l'espai privatiu local actual; les còpies de recuperació tenen controls de borratge independents. Els plans i les llistes privades mai s'inclouen en les exportacions familiars estàndard.

Llistes Obertes → Espai Privatiu o Conjunt → Espai Privatiu per crear una llista de compres, una llista de tasques, un projecte, o una llista de coses a fer, independentment. No cal configurar cap sistema de calendaris ni cercadors d'esdeveniments. Només els Comptes Apple aprovats pel propietari poden visualitzar aquestes llistes. Totes les persones autoritzades per a aquest Espai Privatiu poden veure els seus plans, les seves llistes i el seu historial; no hi ha un públic diferent per a cada llista. Un nen només pot veure una llista de Nadal si el seu Compte Apple està aprovat per a l'Espai Privatiu.

Llocs de l'esdeveniment i Mapes d'Apple

Afegeix opcionalment un lloc o adreça a un esdeveniment. Toca "Obrir a Mapes d'Apple" per cercar aquesta ubicació. Kinly només envia el text de la ubicació que has desat després de tocar; no rastreja la teva ubicació ni realitza cerques mentre escrius. Les ubicacions privades requereixen que el "Espai Privatiu" estigui desbloquejat i una confirmació abans de deixar Kinly. Els Mapes tenen les seves pròpies eines d'historial i privadesa.

Plans privats, projectes i avisos

Crea un pla personal per a qualsevol ocasió amb el nou pla personal. Els horaris són opcionals; crear un pla no requereix configurar un horari infantil ni utilitzar un sistema de trobada d'horaris. "Trobar temps per a nosaltres" compara dues persones adultes i, opcionalment, els fills que tenen activitats independents que heu confirmat.

Les versions actualitzades de les plantilles privades ofereixen les opcions "Editar", "Desar", i "Eliminar". Els borradors es mantenen encriptats en aquest dispositiu, i estan vinculats al calendari i al compte. Desbloqueja l'Espai Privat per reprendre'ls. En desar, es verifica l'accés i es protegeixen les modificacions realitzades per un altre usuari. Les llistes privades admeten la funció "Desfer", permeten seleccionar diversos elements alhora, creen còpies noves, inclouen funcions de "fixació" i ofereixen filtres per a les tasques.

Les notificacions en aquest dispositiu separen els recordatoris de les alertes de canvi. Assignar una tasca no notifica automàticament a ningú. Els recordatoris de tasques personals arriben a les 9 del matí en la data de venciment. Les alertes privades oculten els noms, les hores i les notes. Silenciar les alertes de canvi no silencia els recordatoris ni reprodueix les actualitzacions antigues quan les activeu de nou.

Una funció de cerca de llocs, opcional, envia la vostra consulta escrita a Maps d'Apple només després de que seleccioneu "Cercar". La cerca de llocs privada sol·licita la confirmació prèvia. Els llocs recents es mantenen dins del seu àmbit familiar o privat. Kinly no sol·licita la vostra ubicació actual. En tornar de Maps, es requereix un desbloqueig privat.
