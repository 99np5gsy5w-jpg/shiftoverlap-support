Kinly reads a link only after you select it. Use content you own or are authorized to process. Public visibility and robots permission are not licenses.

Kinly respects robots rules and publisher no-AI, no-archive and no-snippet directives. Sign-in pages, private sharing links and unsafe destinations are unavailable. When access rules cannot be checked, retry later.

Kinly does not impose a precautionary publisher blocklist. Public links, including ODU schedules, may be read when the source and network permit it. Sources may still refuse access, require sign-in or explicitly restrict automated retrieval. Publisher-specific blocks are added only at the app owner’s explicit instruction.

New link imports retain calendar facts and the source address rather than copied descriptions and review quotations. Your own notes, existing events and authorized file imports are preserved.

For access questions or complaints, use GitHub support. Share only a public website address; never post private documents, invitation links or credentials.
